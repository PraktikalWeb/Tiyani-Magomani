# Tiyani Magomani

A modern, responsive investment-information website for Tiyani Magomani. The site presents investment pathways, digital investing guidance, an indicative calculator, FAQs, and enquiry journeys.

Designed and developed by [SlotlyDev](https://slotlydev.co.za).

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run locally

Install the project dependencies, then start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
npm start
```

## Project structure

- `app/` — pages, routes, and global styles
- `components/` — reusable page sections and UI components
- `public/images/` — local site imagery and assets

## Deployment

The project is configured for deployment on Vercel. Connect the repository to Vercel and use the default build command:

```bash
npm run build
```

## Notes

This site does not require API keys or third-party AI services to run.
